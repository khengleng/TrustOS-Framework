# Evidence pack

Everything the pilot's numbers come from. The JSON files are generated by the tests that produce
them; the Markdown is written from those files.

## Generated artefacts

| File                                                   | Generated by                                                    |
| ------------------------------------------------------ | --------------------------------------------------------------- |
| [`simulation-results.json`](simulation-results.json)   | `apps/merchant-wallet-basic/src/sandbox-and-simulation.spec.ts` |
| [`performance-results.json`](performance-results.json) | `apps/merchant-wallet-basic/src/performance.spec.ts`            |
| [`framework-reuse.json`](framework-reuse.json)         | `scripts/pilot-reuse.mjs`                                       |
| [`dependency-audit.json`](dependency-audit.json)       | `npm audit --json`                                              |
| [`test-summary.md`](test-summary.md)                   | `npx vitest run apps/merchant-wallet-basic --reporter=verbose`  |

Regenerate all of them:

```bash
npx vitest run apps/merchant-wallet-basic
node scripts/pilot-reuse.mjs
npm audit --json > docs/pilot/evidence/dependency-audit.json
```

## What is not here

**A backup, a restore report and a DR exercise record.** There is no database and no deployment, so
none was performed. [`continuity.md`](continuity.md) says so plainly rather than estimating.

**A trace.** Correlation ids propagate and are audited; no backend collects them.

**A penetration test report.** None was performed.
